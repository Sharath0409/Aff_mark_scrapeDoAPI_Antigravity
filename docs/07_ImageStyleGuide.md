# RemoteProstor Image Style Guide

## Purpose

This document defines the image standards for all articles published on RemoteProstor.

Its objective is to ensure visual consistency, maintain copyright compliance, improve reader understanding, and maintain a professional appearance across the website.

These standards apply to both Commercial and Informational articles.

---

# Image Philosophy

Images exist to improve reader understanding.

Every image included within an article should have a clear purpose.

Images should support the written content rather than distract from it.

Decorative images with no informational value should be avoided.

---

# Image Categories

RemoteProstor uses two distinct image categories.

- Commercial Images
- Informational Images

Each category follows different sourcing rules.

---

# Commercial Images

## Purpose

Commercial articles recommend products.

Readers expect to see the products being discussed.

Therefore, product images are included to help readers recognize and compare products.

---

## Image Source

Commercial product images should be retrieved from Amazon product listings through the approved automation workflow.

No manual downloading should be required during normal operation.

---

## Image Processing

Before publication, every product image should be:

- Downloaded
- Optimized
- Compressed where appropriate
- Uploaded to the approved Google Cloud Storage bucket

The published article should reference the optimized hosted image.

---

## Image Quality

Product images should be:

- Clear
- High resolution
- Properly cropped
- Undistorted
- Easy to recognize

Images should not be stretched or compressed disproportionately.

---

## Image Placement

Each product should include its corresponding image near the beginning of its review section.

Readers should immediately know which product is being discussed.

---

# Informational Images

## Purpose

Informational images exist to explain concepts rather than display products.

Examples include:

- Ergonomic desk layouts
- Proper sitting posture
- Workspace organization
- Lighting examples
- Cable management
- Home office layouts
- Productivity illustrations

---

## Image Source

All informational images should be generated using AI.

Images should be original.

Images obtained from internet searches should not be used.

Stock photography should not be relied upon.

---

## Educational Value

Every informational image should help readers understand the surrounding content.

Examples include:

- Demonstrating correct monitor height
- Showing proper desk arrangement
- Comparing good and poor posture
- Explaining lighting placement
- Illustrating cable organization

Images should reinforce learning.

---

## Visual Style

Generated images should appear:

- Professional
- Modern
- Clean
- Realistic
- Well lit
- Organized

Avoid excessive artistic effects.

Readers should immediately recognize the subject being illustrated.

---

## Consistency

Images throughout the website should maintain a consistent visual identity.

Where practical, generated illustrations should use similar:

- Perspective
- Lighting
- Color balance
- Composition
- Professional appearance

Consistency helps strengthen the RemoteProstor brand.

---

# Text Inside Images

Images should minimize embedded text.

Whenever text is necessary:

- Keep it short.
- Use readable fonts.
- Ensure sufficient contrast.
- Avoid clutter.

Important explanations should remain within the article rather than inside the image.

---

# Accessibility

Images should remain accessible.

Every published image should include meaningful alternative text.

Alt text should describe the image clearly and accurately.

Alt text should improve accessibility rather than repeat article titles.

---

# Image Dimensions

Images should remain suitable for:

- Desktop viewing
- Tablet viewing
- Mobile viewing

Images should maintain their aspect ratio.

Excessively large files should be avoided when they do not improve reader experience.

---

# Optimization

Images should be optimized before publication.

Optimization should reduce page load time while maintaining acceptable visual quality.

Performance improvements should never noticeably degrade image clarity.

---

# Copyright

RemoteProstor should publish only images that it has the right to use.

Commercial product images should follow the approved affiliate workflow.

Informational images should be AI generated.

Copyrighted third-party images should not be copied into articles without appropriate rights.

---

# Image Placement Guidelines

Images should appear near the section they support.

Readers should never need to scroll long distances to understand the relationship between an image and the surrounding text.

Large gaps between explanation and illustration should be avoided.

---

# Visual Consistency

Every article should maintain a balanced layout.

Images should not overwhelm the written content.

Similarly, large sections of complex explanations should not appear without supporting visuals where illustrations would improve understanding.

The objective is to maintain a comfortable reading experience.

---

# Image Quality Checklist

Before publication, every image should satisfy the following:

- Relevant to the topic
- Clear and readable
- Properly optimized
- Correctly positioned
- Appropriate dimensions
- Professional appearance
- Copyright compliant
- Accessible through meaningful alt text

Only images meeting these standards should be published.

---

# Guiding Principle

Every image should answer one question:

> "Does this image genuinely help the reader understand the content better?"

If the answer is no, the image should not be included.
